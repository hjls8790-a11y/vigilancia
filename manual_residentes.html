🚗 Etiquetas Vehiculares (Stickers)

La etiqueta de acceso vehicular es un beneficio exclusivo e intransferible para residentes de El Cielo Parque Residencial.

Funcionamiento en Caseta

  • Apertura automática del Carril Derecho (Exclusivo Residentes): Su uso es prioritario. Cuenta con radares de largo alcance para lectura rápida.
  • Apertura del Carril Central: Para visitas y residentes.

Políticas de Asignación Obligatorias

  • Las etiquetas se otorgan únicamente para vehículos que el residente compruebe documentalmente que pernoctan en su domicilio.
  • No se emiten etiquetas para familiares no residentes, amigos o conocidos, sin excepciones.
  • El sticker no tiene fecha de vigencia.
🔄 Reemplazos y Cambios:
Si cambia de vehículo, es obligatorio reportarlo a la Administración para dar de baja la etiqueta anterior y adquirir una nueva. En caso de falla técnica del sistema, se reemplaza gratuitamente.

📱 Aplicación "El Cielo"

Como propietario, usted tiene derecho a vincular hasta 2 dispositivos móviles. La App le permite gestionar accesos de manera cómoda, pero con estricta responsabilidad.

Panel de Control Principal

Al abrir la aplicación, visualizará botones para la apertura remota de visitas, accesos peatonales y salida vehicular.

Generación de Invitaciones

En la sección de Invitaciones, podrá generar:

  • Pases de un solo uso: Para visitas casuales.
  • Pases por tiempo: Para eventos, definiendo hora de inicio y término.
🛡️ Bondades del Sistema:
Sus visitas ingresarán de forma fluida. El equipo de monitoreo realiza una inspección visual remota para garantizar que se cumpla el reglamento.
⚠️ RESTRICCIONES INQUEBRANTABLES:
  • Queda estrictamente prohibido aperturar puertas si no se encuentra en el sitio o no tiene contacto visual. Abrir a ciegas vulnera la seguridad de todos.
  • Las invitaciones por App son exclusivas para familiares y visitas de confianza.
  • PROHIBIDO generar invitaciones por App para trabajadores, plomería, electricidad o jardinería. Ellos tienen su propio protocolo obligatorio.

📞 Sistema de Interfón

Es la vía principal de comunicación con nuestra caseta de seguridad.

Pasos para su visita en caseta:

  1. Presionar la tecla "Call" en el tablero.
  2. Esperar la respuesta de la operadora.
  3. Indicar claramente el número de domicilio.
  4. Aguardar la conexión telefónica.

Protocolo de Seguridad y Escolta

Al autorizar el acceso, el agente de monitoreo registra identificación y placas. Un agente de patrullaje escolta a la visita directamente hasta su domicilio. En caso de proveedores permitidos, se verifica que no se desvíen de su ruta.

📌 Casos de Uso Permitidos:
Utilice el interfón para autorizar: trabajadores domésticos, gaseras, paqueterías, Uber o entrega de comida.
⚠️ RESTRICCIÓN ABSOLUTA:
No utilice el interfón para autorizar el ingreso de contratistas de albañilería o mantenimiento pesado. Todo trabajo debe registrarse obligatoriamente en la plataforma CondoSenior.

🛠️ Registro de Proveedores

Para mantener un entorno seguro, todo trabajador, contratista o proveedor técnico debe ser registrado previamente en la plataforma CondoSenior.

Acceder a Plataforma CondoSenior

Pasos para el Alta

  1. Acceda a la plataforma con su Código de Referencia.
  2. Seleccione el tipo de ingreso.
  3. Complete los datos exactos del trabajador, incluyendo fotografías de rostro e INE.
  4. El sistema generará un código QR para el proveedor.

Parámetros de Anticipación Obligatorios

  • El registro es obligatorio con al menos 24 horas de anticipación.
  • Casos Emergentes: Pueden registrarse el mismo día, pero es forzoso avisar a la Comandancia de Seguridad para su aprobación expedita. Sin registro previo, se negará el acceso en caseta.
🛡️ Nuestro Compromiso:
Este control estricto nos permite tener un censo exacto de personas ajenas al residencial y prevenir incidentes.
